# Windows 1.0.2 图片和文件打开修复

旧版传输记录只显示名称和进度，没有双击打开入口，也未记录接收文件重命名后的
最终路径。1.0.2 支持在传输页用鼠标左键双击已完成记录的文件名或卡片区域，
调用 Windows 为该文件类型设置的默认应用。

## 使用与升级

1. 从旧版系统托盘菜单选择“退出”。只关闭主窗口会继续在后台运行。
2. 完整解压 `zhanhBlueB-Windows-1.0.2-win-x64.zip`，运行其中的 `zhanhBlueB.exe`。
   手机保持 Android 1.0.0，无需重新安装 APK；重新连接电脑即可。
3. 传输一张图片，等待记录显示“已完成”，再双击文件名或记录卡片。
   已完成的普通文件也支持同样操作，重名文件打开实际保存的 `(1)`、`(2)` 文件。

电脑剪贴板图片发送成功后，会在下载目录的 `zhanhBlueB` 文件夹保存一份
`clipboard.png`，同名自动加序号，便于从发送记录再次打开。普通文件的发送记录
打开原始电脑文件。若额外 PNG 副本无法保存，发送成功状态仍保留，页面会提示
本地保存失败。

传输记录保存在当前运行期间，重启后旧文件仍在下载目录。传输中、失败或取消的
记录不能打开；文件已删除/移动或缺少默认应用时显示中文提示。接收到文件不会
自动启动外部应用。

## 验证边界

23 项单元测试、WPF 记录容器/文件名/内联文字的双击事件检查，以及本地保存失败
不误报传输失败的检查通过。WPF 测试记录启动参数，不实际操作默认图片查看器。
实际鼠标双击和 Windows 默认图片应用的兼容性仍需安装新版本后验收；完整结果
见 [验证记录](verification.md)。
